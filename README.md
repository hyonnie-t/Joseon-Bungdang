# Joseon-Bungdang — 붕당 분화 시뮬레이션

고려 말 신진 사대부 분화 → 훈구·사림 → 붕당(동·서·남·북인, 노론·소론)까지 **다섯 번의 갈림길**에서
"나라면?"을 고르고, 가장 고민한 장면 하나에 글을 쓰는 history26 수업 웹앱. 대영중 3학년 대상.

- plain HTML/CSS/JS. 빌드 도구·프레임워크·CDN 없음. GitHub Pages(`hyonnie-t`)에 그대로 올린다.
- 파일: `index.html`(뼈대) · `config.js`(설정) · `data.js`(콘텐츠) · `logic.js`(판정·제출문, DOM 무관) · `app.js`(화면) · `style.css`.
- 독립 앱이다. 기존 사화 앱(`Joseon-Sarim`)과 데이터 연동이 없다.

## 실행·점검

```
python3 -m http.server          # http://localhost:8000/?preview=1
node tests/logic.test.mjs       # 판정 로직 단위 테스트
node scripts/verify.mjs         # 배포 전 점검(검증 라벨·쪽수·CDN·TODO 0건, 시트 URL 원본 일치)
```

`?sid=30512&name=이름` 으로 학번·이름 자동채움, `?preview=1` 은 미리보기(시트 저장 없이 동작).

## 포털 연결

1. 포털 `config.js`에 차시(활동)를 등록할 때 activity id를 이 앱의 `CONFIG.GAME_NAME`(`붕당분화_나라면_시뮬레이션`)과
   **글자 하나까지 동일하게** 맞춘다. 차시 번호를 붙여 바꾸려면 `config.js`와 포털을 같이 바꾼다.
2. 제출은 `history26_backend`의 기본 경로(`gameName` 필수, 학생당 1행 게임활동_로그)를 그대로 쓴다.
   **스키마 변경·새 action 없음 → Apps Script 재배포 불필요.** 필요해지면 "배포 관리 > 수정 > 새 버전"만(새 배포 금지).

| 필드 | 값 |
|---|---|
| `choiceSummary` | `강경 n · 온건 5-n / 유형명` |
| `diffSummary` | 가장 고민한 분기명 |
| `reflection` | `[가장 고민한 장면]`·`[내가 고른 선택]` + 서술 2칸 원문 전체(라벨 포함) |
| `choicesJson` | `{ "choices": [{stage, hard, choiceId}, …], "focusStage": n, "dir": "other|fact|whatif" }` (문자열) |

## 설계 메모(학생 화면에는 나오지 않는 내용)

- 축은 "강경 ↔ 온건" 하나. `hard:true/false`는 재미용 설계 장치이며 역사적 주장이 아니다.
- 성향 결과는 hard 횟수(0~5)로 6유형. 붕당명은 결과에 쓰지 않고, 분기별 "네가 선 자리"로 따로 보여 준다.
- 선택지 표시 순서는 첫 분기 무작위 후 교대. 강경이 항상 위/아래에 오지 않는다.
- 글쓰기는 유형이 아니라 **선택 장면**에 붙인다. 예시 문장·자동완성·채워진 placeholder 없음(재도입 금지).
- 글쓰기: ① 내 선택과 이유(필수) → ①을 쓰면 열리는 ②는 학생이 이어 쓸 방향을 하나 고른다. 반론·재반박이 꼭 아니어도 된다.
  방향은 고르지 않은 쪽의 말에 대답(other) / 실제 역사와 내 선택 비교(fact) / 다른 쪽을 골랐다면(whatif). 학생이 먼저 판단하고 그 뒤에 이어 쓴다.
- 안내는 질문·순서만 준다(`data.js`의 `WRITING`의 `steps`). 힌트 토글을 열면 "생각 사다리"(질문 3개)와, 이미 본 선택지의 얻는 것/감수할 것이 다시 나온다.
  결론 문장·예시 문장·문장 빈칸 틀·자동 채우기는 없다(재도입 금지).
- "고르지 않은 쪽"은 선택지에 적힌 문장(text·sub)이고, 실제 인물의 발언처럼 보이지 않게 stand(인물명)는 붙이지 않는다. 화면에 창작임을 밝히는 문구가 있다.
- 광해군 중립외교는 이 앱에서 뺐다(왜란·호란 차시로 이관).
- 교과서 쪽수는 `data.js` 상단 주석에만 있다. 화면 문자열에는 쪽수를 쓰지 않는다.
- 분기 4·5의 배경 일부와 통설 대응(북인/남인, 노론/소론)은 교과서 밖 내용이라 "흔히 ~로 설명한다"로만 쓴다.
  남·북인 분화의 원인과 시점은 자료마다 달라 그 문구를 유지한다. "왕위 계승 문제로 갈렸다"는 서술 금지.
- 서술 최소 분량: 칸마다 공백 제외 20자(`CONFIG.MIN_CHARS`, 한두 문장). 효과음 없음. 백성 관점 문항 없음(5분기 유지).

## 삽화 넣는 법

`images/` 폴더에 `intro.webp`, `s1.webp` ~ `s5.webp`를 넣으면 시작 화면과 각 장면 위에 나타난다(16:9, 장당 200KB 안팎 권장).
파일이 없으면 그 자리는 조용히 사라져서 글만 보인다. 파일 이름·설명(alt)은 `data.js`의 `img`에서 바꾼다.
삽화는 상상해서 그린 그림이라 화면에 "상상 그림" 문구가 자동으로 붙는다. 그림 속 글자는 쓰지 않는다.

## 배포 후 확인(로컬에서는 script.google.com 접근이 막혀 검증 불가)

학번 하나로 실제 제출해서 게임활동_로그에 1행이 생기는지, 포털에서 해당 차시가 "완료"로 잡히는지 확인한다.
